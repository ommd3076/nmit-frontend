# UI/UX Pro Max - Design Intelligence

## Core Rules & Priorities
1. **Accessibility (CRITICAL)**: 4.5:1 text contrast minimum, visible focus rings, aria-labels for icon buttons, keyboard navigable.
2. **Touch & Interaction (CRITICAL)**: Minimum target size 44×44px, ≥8px spacing, instant feedback on tap/click.
3. **Typography**: Base 16px, line-height 1.5 for body, 1.15-1.25 for headings, unitless line heights, tabular-nums on all metrics, counters, and currencies.
4. **Layout**: Strict responsive layout, zero horizontal overflow, optical padding.
5. **Color & Elevation**: Semantic tokens only, layered box shadows for elevation instead of harsh borders, OKLCH or calibrated hex palettes.
6. **Charts & Data**: EvilCharts/Recharts with accessible contrast, gradient fills, glowing node accents, custom tooltips, never relying on color alone.
